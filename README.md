# ISA | студия перманентного макияжа — сайт

Статический сайт: HTML + CSS + JS. Без сборки, без сервера, без зависимостей.

## Как открыть

Дважды кликнуть по `index.html` — откроется в браузере.

## Структура

```
index.html        — вся страница: тексты, разделы, контакты
css/style.css     — оформление
js/data.js        — МАСТЕРА, ЦЕНЫ, РАБОТЫ, ОТЗЫВЫ   ← правится чаще всего
js/app.js         — логика: лента, блоки мастеров, галерея, лайтбокс
assets/works/     — работы студии и карточки мастеров
assets/masters/   — работы каждого мастера по услугам
assets/studio/    — фотографии самой студии
assets/favicon.svg — значок во вкладке браузера
```

## Фотографии

В `assets/works/` лежат настоящие работы студии и карточки мастеров, взятые
из сообщества ВКонтакте `vk.ru/club235192174`, ширина 1440 пикселей.
Если есть оригиналы с телефона, замените файлы на них, имена оставьте
те же: страница станет ещё резче на экранах с высокой плотностью точек.

Снимки показываются без обработки, в своём цвете. Не тонируйте их
и не накладывайте цветные заливки: смотреть приходят именно на работу.

Галерея «Работы студии» внизу страницы берёт кадры из массива `WORKS`
в `js/data.js`:

```js
{ src: "assets/works/brovi-gradient-01.jpg", alt: "Брови в технике градиент" },
```

`alt` — короткое описание. Его читают поисковики и программы для незрячих.

В этой галерее только кадры без надписей поверх фотографии: логотипы
и подписи из ленты на сайте выглядят чужеродно. Сетка сама подбирает
число колонок, поэтому кадров может быть сколько угодно.

## Мастера: прайс и работы

Каждый мастер — свой блок на странице: карточка, прайс и работы по услугам.
Всё это лежит в `js/data.js`, массив `MASTERS`. Один элемент — один мастер:

```js
{
  id: "sabina",                       // латиницей, попадёт в адрес якоря
  name: "Сабина",
  gen: "Сабины",                      // родительный падеж для заголовков
  role: "Владелец студии, тренер и топ-мастер",
  bio: "Текст о мастере",
  photo: "assets/works/master-sabina.jpg",
  photoAlt: "Описание фото",
  linkHref: "https://t.me/isa_sabi",
  linkText: "Написать Сабине",

  price: [                            // группы услуг с ценами
    { group: "Перманентный макияж бровей и губ", items: [
        ["Первичная процедура", "9 000 ₽"],
        ["Коррекция до 1,5 месяца", "4 000 ₽"]
    ]}
  ],

  works: [                            // работы, разложенные по услугам
    { title: "Перманентный макияж бровей", shots: [
        "assets/masters/sabina-brows-01.jpg",
        "assets/masters/sabina-brows-02.jpg"
    ]}
  ]
}
```

Порядок мастеров в массиве — порядок блоков на странице. Порядок групп
в `price` и наборов в `works` тоже сохраняется.

В блоке мастера показывается только его карточка: имя и должность
напечатаны на самой карточке, поэтому дублировать их текстом незачем.
Поля `role`, `bio`, `linkHref` и `linkText` в данных остались — если
захотите вернуть текст рядом с карточкой, он уже есть.

Заголовки «Прайс …» и «Работы …» строятся из поля `gen` — имени
в родительном падеже.

Работы мастера показываются лентой: список кадров повторяется, пока
не наберётся восемь, затем дублируется целиком — так лента едет по кругу
без видимого стыка. Скорость одна для всех лент, длительность считается
из числа кадров. Под курсором лента останавливается.

Фотографии работ лежат в `assets/masters/`, имена вида
`мастер-услуга-номер.jpg`. Снимки длиннее 1400 пикселей уменьшены,
исходники с телефона весили по 5–7 МБ. Снимки, которые и так были
небольшими, скопированы байт в байт: повторное сжатие JPEG портит
тонкие волоски на бровях.

Прайсы перенесены с прайс-листов самих мастеров. Общей таблицы услуг
на сайте больше нет: у Сабины и Динары цены на один и тот же перманент
разные, и единый список им противоречил.

## Фотографии студии

Лента на главном экране берёт кадры из массива `STUDIO` в `js/data.js`,
файлы лежат в `assets/studio/`. Список дублируется в коде, чтобы лента
шла по кругу без стыка.

## Что нужно сделать до публикации

### 1. Добавить отзывы

Массив `REVIEWS` в `js/data.js` пустой, поэтому в разделе «Отзывы» стоит
ссылка на Instagram. Когда появятся настоящие отзывы, впишите их:

```js
{ text: "Текст отзыва", who: "Имя клиента" },
```

Раздел сам переключится на карточки. **Выдуманные отзывы не добавляйте.**

### 2. Дописать недостающее

- **Режим работы.** Нигде не указан, на сайте его нет. Добавьте в раздел
  «Студия» в `index.html`.
- **Долговременная укладка бровей.** В старом прайсе из ВК она стоила
  1 000 ₽, но ни на одном прайс-листе мастеров её нет. Скажите, кто
  её делает, — добавлю в его блок.
- **Реквизиты и лицензия.** Инъекционная косметология — медицинская услуга.
  Если она оказывается, на сайте нужны данные организации и лицензия.
  Формулировки стоит согласовать с юристом до запуска.

Тексты о мастерах взяты с их же карточек «меня зовут». Сабина — владелец
студии, тренер и топ-мастер. Динара — мастер студии с медицинским
образованием и опытом больше двух лет. Диана Чернова — врач-косметолог.
Если формулировки устарели, правьте в `index.html`, раздел «Мастера».

На опубликованной карточке Дианы стоит значок «листай карусель» — он был
нужен ленте, а не сайту. Сейчас он закрыт прямоугольником цвета фона:
правило `.master__photo--patch::before` в `css/style.css`. Пришлите файл
карточки без значка, положите его как `assets/works/master-diana.jpg` —
и это правило вместе с классом `master__photo--patch` можно удалить.

## Как менять контакты

`index.html`. Телефон, адрес и ссылки написаны прямо в разметке, а не
в скрипте, — так они видны даже если JavaScript не отработает.

Телефон встречается в четырёх местах: в разделе «Записаться», в плавающей
кнопке звонка, в блоке `application/ld+json` и в описании страницы.
Меняйте везде.

`https://vk.ru/club235192174`, Instagram `https://www.instagram.com/isa.studio.pmu/`.
На главном экране ВКонтакте не показывается, в разделе «Записаться» есть.

Координаты студии: 54.367525, 48.568736. Геометка из старого поста ВК
(54.310763, 48.364267) указывала в Засвияжский район, а не на Зырина, 17 —
не используйте её.

## После правки стилей или скриптов

В `index.html` у файлов `css/style.css`, `js/data.js` и `js/app.js` стоит
номер версии: `?v=13`. Браузеры держат эти файлы в кэше, и без смены номера
посетитель может видеть старое оформление. Меняете стили или данные —
увеличьте номер во всех трёх строках на единицу.

## Оформление

Цвета, шрифты и размеры собраны в начале `css/style.css`, в блоке `:root`.
Поменяете там — поменяется на всей странице. Описание системы — в `DESIGN.md`.
