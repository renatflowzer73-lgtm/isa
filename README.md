# ISA | студия перманентного макияжа — сайт

Статический сайт: HTML + CSS + JS. Без сборки, без сервера, без зависимостей.

## Как открыть

Дважды кликнуть по `index.html` — откроется в браузере.

## Структура

```
index.html        — вся страница: тексты, разделы, контакты
css/style.css     — оформление
js/data.js        — УСЛУГИ, ЦЕНЫ, РАБОТЫ, ОТЗЫВЫ   ← правится чаще всего
js/app.js         — логика: лента работ, прайс, галерея, лайтбокс
assets/works/     — фотографии
assets/favicon.svg — значок во вкладке браузера
```

## Фотографии

В `assets/works/` лежат настоящие работы студии и карточки мастеров, взятые
из сообщества ВКонтакте `vk.ru/club235192174`, ширина 1440 пикселей.
Если есть оригиналы с телефона, замените файлы на них, имена оставьте
те же: страница станет ещё резче на экранах с высокой плотностью точек.

Снимки показываются без обработки, в своём цвете. Не тонируйте их
и не накладывайте цветные заливки: смотреть приходят именно на работу.

Добавить новую работу: положить файл в `assets/works/` и вписать строку
в `js/data.js`, массив `WORKS`:

```js
{ src: "assets/works/brovi-gradient-01.jpg", alt: "Брови в технике градиент" },
```

`alt` — короткое описание. Его читают поисковики и программы для незрячих.

Первый кадр в списке показывается крупным. Общее количество лучше держать
кратным сетке: 9, 13 или 17 кадров заполняют её без пустых клеток.

## Что нужно сделать до публикации

### 1. Добавить отзывы

Массив `REVIEWS` в `js/data.js` пустой, поэтому в разделе «Отзывы» стоит
ссылка на Instagram. Когда появятся настоящие отзывы, впишите их:

```js
{ text: "Текст отзыва", who: "Имя клиента" },
```

Раздел сам переключится на карточки. **Выдуманные отзывы не добавляйте.**

### 2. Дописать недостающее

- **Режим работы.** Нигде не указан, на сайте его нет. Добавьте в раздел
  «Студия» в `index.html`.
- **Цены на косметологию.** Сейчас стоит «по консультации».
- **Реквизиты и лицензия.** Инъекционная косметология — медицинская услуга.
  Если она оказывается, на сайте нужны данные организации и лицензия.
  Формулировки стоит согласовать с юристом до запуска.

Тексты о мастерах взяты с их же карточек «меня зовут» из ВКонтакте.
Сабина — владелец студии, тренер и топ-мастер. Динара — мастер студии
с медицинским образованием и опытом больше двух лет. Если формулировки
устарели, правьте в `index.html`, раздел «Мастера».

## Как менять цены

`js/data.js`, массив `SERVICES`:

```js
{
  name: "Перманентный макияж бровей",
  sum:  "7 000 — 9 000 ₽",
  hint: "Пояснение под названием, можно оставить пустым"
},
```

Порядок строк в файле — это порядок в прайсе на сайте.

## Как менять контакты

`index.html`. Телефон, адрес и ссылки написаны прямо в разметке, а не
в скрипте, — так они видны даже если JavaScript не отработает.

Телефон встречается в четырёх местах: в разделе «Записаться», в плавающей
кнопке звонка, в блоке `application/ld+json` и в описании страницы.
Меняйте везде.

## Оформление

Цвета, шрифты и размеры собраны в начале `css/style.css`, в блоке `:root`.
Поменяете там — поменяется на всей странице. Описание системы — в `DESIGN.md`.
